À partir de l’Exercice 4, tous les entraînements et expérimentations ont été réalisés sur 
Google Colab afin de bénéficier de l’accélération GPU (Tesla T4) et de réduire le temps d’exécution
des modèles.

Le fichier grid_search_results.csv généré lors de l’Exercice 4 est enregistré directement à la racine du projet.
Ce fichier contient l’ensemble des résultats obtenus lors de la recherche exhaustive des hyperparamètres (Grid Search),
notamment les différentes configurations testées et leurs performances respectives.

Les figures générées automatiquement par les scripts (courbes d’apprentissage, étude d’ablation, résultats du Grid Search, etc.)
sont enregistrées dans le dossier : rapport_images/

Les modèles sauvegardés (.pth) ainsi que les autres fichiers de sortie sont conservés
dans leurs emplacements respectifs indiqués par chaque script.
